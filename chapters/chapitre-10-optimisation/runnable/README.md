# Runner du chapitre 10

Ce runner vérifie les six scripts avec leurs démonstrations locales. Il ne
télécharge aucun modèle et n'effectue aucun appel distant.

```bash
python chapters/chapitre-10-optimisation/runnable/run_chapter.py
```

Dans le notebook, vous pouvez ensuite activer OpenAI pour le streaming, le
résumé et le routage, ou Hugging Face pour le token pruning.
