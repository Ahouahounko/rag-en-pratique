# Runner du chapitre 12

Le runner exécute les cinq scripts et affiche le prompt robuste sans dépendance
externe ni appel distant.

```bash
python chapters/chapitre-12-bonnes-pratiques/runnable/run_chapter.py
```

Les harnais de chunking et de journalisation attendent ensuite vos propres
composants par injection de dépendances.
